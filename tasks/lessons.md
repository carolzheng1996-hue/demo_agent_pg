# Lessons

- 日期: 2026-03-03
- 触发: 用户要求将基线模型升级为深度时序模型。
- 规则: 当用户提出“拓展为深度模型”这类纠正时，优先直接修改现有 subagent 训练逻辑，并保持主编排接口不变，避免影响 agentloop/runtask/todo 机制。
- 规则: 完成纠正后同步更新依赖与文档，确保实现可被直接运行。

- 日期: 2026-03-05
- 触发: 用户纠正“不是官方 OpenAI key，而是第三方平台购买的 key/base”。
- 规则: 设计 LLM 配置时默认按 OpenAI 兼容协议处理，优先支持 `api_key + api_base`，不要把能力绑死在 provider 名称上。
- 规则: 参数和文档要覆盖用户常见口径（如 `API_BASE`、`--api-base`），避免只有内部命名（如 `base_url`）。

- 日期: 2026-03-05
- 触发: 用户要求改为 `.env` 方式配置 API 信息。
- 规则: 当涉及 key/base/model 配置时，默认提供 `.env` 自动加载能力，并配套 `.env.example` 与 `.gitignore`。
- 规则: 文档中优先展示 `.env` 用法，同时保留 CLI 参数覆盖路径。

- 日期: 2026-03-05
- 触发: 用户反馈 key/base 已配置但 `llm_test.py` 仍请求失败。
- 规则: 第三方 OpenAI 兼容平台调试时，优先排查系统代理变量（`http_proxy/https_proxy`）对 SDK 的影响，并提供可配置的 `trust_env_proxy` 开关。
- 规则: 测试脚本需输出结构化诊断（模型探测、状态码、响应体片段），避免仅返回笼统错误。

- 日期: 2026-03-05
- 触发: 用户要求 orchestrator 不再依赖关键词固定模板，而由主智能体直接生成计划。
- 规则: 对编排层需求，优先让 LLM 生成结构化 plan，再由本地规则做依赖校验与纠偏，避免“纯模板计划”僵化。
- 规则: 计划生成必须保留可执行兜底（无 key/模型异常时自动回退），并记录 `plan_source` 与 `plan_reason` 便于排障。

- 日期: 2026-03-09
- 触发: 用户纠正 `5_DGagent` 不应继续使用自写 `LLMClient`，而应直接复用其提供的 `LLM/` 目录与 `get_llm().invoke()` 方式。
- 规则: 当项目内已提供明确的 LLM 接入实现时，优先直接复用该实现，不再平行引入第二套客户端封装。
- 规则: 涉及 API/Base/代理配置时，默认先对齐项目内 `.env` 自动加载机制，不要求用户重复通过 CLI 手动传参。

- 日期: 2026-03-09
- 触发: 用户进一步要求根目录旧版 `orchestrator/subagents` 也统一到同一套 `LLM/` 接口。
- 规则: 同一仓库内若存在多个 agent 入口，LLM 接入必须统一到同一实现，避免一个项目内并存多套配置和调用方式。
- 规则: 重构子系统后，要继续检查主系统是否还残留旧接口引用，不只修新增目录。

- 日期: 2026-03-09
- 触发: 用户在 `LLM` 目录重新提供 `.env`，其中使用的是 `OUT_OPENAI_API_KEY/OUT_OPENAI_API_BASE`。
- 规则: 适配项目内现有 LLM 接口时，必须先核对实际 env 变量命名，再决定 `get_llm()` 的参数，例如是否需要 `is_outside=True`。
- 规则: 当用户明确提供了现成 LLM 目录时，优先修改外层适配层，不改动其目录内核心实现，除非用户明确要求。

- 日期: 2026-03-09
- 触发: 用户纠正 LoongFlow 风格优化代码必须放在新的 `loongflow_DGagent` 目录，而不是直接覆盖 `5_DGagent`。
- 规则: 当用户明确要求“放到新目录/新模块”时，必须先复制基础骨架到新位置，再在新位置迭代，不要直接修改已有实现。
- 规则: 若已误改旧目录，优先撤回本轮改动，再按用户指定的目标目录重做。

- 日期: 2026-03-09
- 触发: 用户要求 `5_DGagent` 和 `loongflow_DGagent` 必须能在各自目录内直接运行 `main.py`，且不能依赖上一级文件夹源码。
- 规则: 当用户要求子目录项目可独立运行时，必须把共享工具复制到该目录，并为导入增加“包内运行 + 直接脚本运行”双模式兼容。
- 规则: 文档中的启动方式要与实际运行方式一致，不应继续保留额外 wrapper 脚本作为主入口。

- 日期: 2026-03-09
- 触发: 当前仓库 `AGENTS.md` 明确要求 Python 脚本需由用户亲自运行。
- 规则: 在本仓库中进行 Python 级验证前，先遵守 `AGENTS.md` 约束，由用户执行脚本并返回输出；不要自行运行 `python *.py`。
- 规则: 若需要验证结果，优先通过代码检查、diff 和用户回传的终端输出推进，而不是绕过仓库级运行约束。
